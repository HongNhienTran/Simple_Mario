## ✨ Điểm nổi bật

- **Giao diện vỏ máy Nokia Champagne Gold:** Mô phỏng chiếc điện thoại Nokia cổ điển với thanh trạng thái (cột sóng 5 vạch, pin, thư), cụm phím D-Pad mạ Crom và bàn phím T9 bấm được.
- **Đồ hoạ Pixel Art:** Màn hình chuẩn tỷ lệ **240×320**, nhân vật Mario, ống cống, khối gạch hỏi chấm, quái nấm Goomba, lâu đài và công chúa Peach.
- **Âm thanh 8-bit chân thực:** Sử dụng Web Audio API tự tổng hợp âm thanh retro (tiếng nhảy, nhặt coin leng keng, đạp quái, nhạc mừng chiến thắng) mà không cần tải bất kỳ file mp3 nào từ bên ngoài.
- **Tương thích đa nền tảng:** Chơi mượt mà trên cả máy tính (bàn phím) và điện thoại di động (cảm ứng cụm phím Nokia).

## ⌨️ Hướng dẫn điều khiển

| Thao tác | Bàn phím máy tính | Bấm trên thân máy Nokia |
| :--- | :--- | :--- |
| **Di chuyển Trái / Phải** | `A / D` hoặc `← / →` | Phím `4` / `6` hoặc D-Pad `◀ / ▶` |
| **Nhảy lên** | `Space` / `W` / `↑` *(giữ để nhảy cao)* | Nút giữa `●` hoặc Phím `2` / `5` |
| **Bắt đầu / Chơi lại** | `Enter` hoặc `Phím 5` | Nút giữa `●` hoặc Nút Home `⌂` |
| **Bật / Tắt âm thanh** | — | Nút `🔔` (Softkey phải) |
